# Fonts of the simulated letters

Shipped with the package so the dataset is rebuilt bit by bit on any machine. All are free to redistribute.

* `main/` — the three fonts of every scene (train, validation, test): DejaVu Sans, DejaVu Serif (Bitstream Vera
  licence) and STIX General (SIL OFL), a sans, a serif and a Times-like face.
* `aux/` — extra faces used ONLY in the auxiliary training scenes (style diversity for the seen classes; never in
  validation or test): DejaVu variants (Bitstream Vera), STIX bold (OFL), Computer Modern `cm*` (BaKoMa, as shipped
  with matplotlib), Roboto and Roboto Mono (Apache 2.0), Open Sans, Inter, Inconsolata, Space Mono, DM Sans, Geist,
  Source Code Pro, League Gothic (SIL OFL), Ubuntu and Ubuntu Mono (Ubuntu Font Licence).
